№ 01 — FACTORY · THE INDEX

Nothing gets cut blind.

Factory reads every clip before it touches one: quality scores, duration, resolution, camera body and everything the file will give up — GPMF telemetry included. Claude writes a scene description; transcription runs locally, timestamped. All of it lands in one database, and every edit downstream is a query against it.

№ 02 — SPOTTER

Show it. It finds it.

Hand Spotter a few frames — find these objects — and point it at these videos. Three competing detectors scan and score against each other. DinoV2 takes the local guess (“soccer cleat”); Gemini, armed with your hints and the web, names it for real (“Mercurial Superfly 11 Elite — Breakout pack”).

INPUTreference frames + optional hint (“this is from the 2026 World Cup”)
SCANthree detectors run head-to-head, scored per hit
IDENTIFYlocal guess by DinoV2 · real answer by Gemini + web
RESULTa confidence-coded timeline of every appearance
SNIPevery hit snipped from its source video and filed to a target folder
№ 03 — SAFE SEND
Safe Send
VERIFIED OFFLOAD

Old card in a drawer? Don’t wipe anything on faith. Safe Send hashes every file on the card — bit-accurate, not filename matching — and checks it against your archive. Whatever isn’t backed up comes home in one click, filed to your folder scheme. Then, and only then, is the card clear.
