№ 01 — FACTORY · THE INDEX

Know your footage.

Factory reads every clip before it touches one: quality scores, duration, resolution, camera body and everything the file will give up — GPMF telemetry included. Claude writes a scene description; transcription runs locally, timestamped. All of it lands in one database, and every edit downstream is a query against it.

№ 02 — SPOTTER

Image search for your archive.

Hand Spotter a few frames — find these objects — and point it at these videos. Three competing detectors scan and score against each other. Optionally, Gemini leverages all available context and the web to validate the quality of each match.

INPUTreference frames + optional hint for the language-input model
SCANthree detectors run head-to-head, scored per hit
IDENTIFYlocal guess by DinoV2 · real answer by Gemini + web
RESULTa confidence-coded timeline of every appearance
SNIPevery hit snipped from its source video and exported to a target folder
№ 03 — SAFE SEND

Files in, safe and sorted.

Safe Send does two jobs, in one pass. First, ingest: every card enters your archive through it, filed straight into your folder scheme, so everything downstream stays organized. Second, verify: it hashes every file — bit-accurate, not filename matching — and checks it against your archive, catching anything that never made it across. Then, and only then, is the card clear to wipe.
